# Ways to contribute

Contributions can improve Nota's code, documentation, tests, accessibility, translations, and bug reports. Start with the [contribution guide](CONTRIBUTING.md).

- Search [GitHub Issues](https://github.com/madcodeorg/nota/issues) and open a reproducible report or scoped proposal.
- Submit a focused [pull request](https://github.com/madcodeorg/nota/pulls) with relevant validation.
- Improve build instructions or clarify user-facing documentation.
- Improve translations in `packages/frontend/i18n` while preserving generated-file workflows.

There is no guaranteed response or release schedule. Maintainers review changes and choose release contents after validation. Do not send private workspace data, credentials, or recordings in public reports.
