A few things
you might wonder.

Does Nota work offline?

Notes work offline. Local AI works after you install its models. Initial model downloads need an internet connection.

Do I need an account?

No. Google connection is optional for Drive sync.

Can I use my own AI provider?

Yes. Use your own provider keys when you choose. Hosted providers need internet access and receive the context you send them.

Where can I get the desktop app?

Download the current installer for Apple-silicon Macs from the download page. For release notes and installer files, visit GitHub Releases. Windows, Linux, and Intel Mac installers are not currently published.
