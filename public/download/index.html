Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Signed Windows builds are produced only by GitHub Actions from the public source code, and every release is approved by hand before it is signed. Bundled third-party libraries keep their own signatures or ship unsigned.

Committers and reviewers: Mad Code AI Studio members. Approvers: Mad Code AI Studio owners.

Privacy: Nota does not send data to other networked systems unless you turn on a feature that does, such as Google Drive sync or a cloud AI provider. See the privacy policy.
