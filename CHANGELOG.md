# Changelog

All notable changes to Nota are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Installers and release notes are published on [GitHub Releases](https://github.com/madcodeorg/nota/releases).

## 0.1.11

- Updated the desktop runtime, HTML sanitizer, and network dependencies with the latest security fixes.

## 0.1.9

- Graph view: see how your notes link together and jump to any note from the map.
- Tasks view with due dates and daily reminders, plus a daily brief in your journal with due tasks and meeting notes.
- Quick capture from anywhere into today's journal.
- Save a web page as a note from its URL.
- Extract text from images and PDFs into your note (macOS).
- Connect MCP servers to the AI assistant from Integrations.
- The AI assistant can now list your tasks and note links, add to your journal, check off tasks and save web pages as notes (each change asks for approval and can be undone). AI edits now respect locked pages.
- Import from Obsidian, Notion and Bear, and copy any note as Markdown.
- Lock a page against accidental edits, focus mode, and word count with reading time.
- Unlinked mentions and related notes under each page, and a simpler sidebar.
- Many editor fixes for tables, kanban, code blocks, LaTeX and edgeless mode.

## 0.1.8

- Nota now runs on Windows (x64). The installer is not signed yet, so Windows shows a SmartScreen warning the first time you open it.
- Sign in with ChatGPT or use your own AI provider, with simpler AI settings.
- The AI assistant decides what to do from your request, writes its own replies after acting, and can move notes to the trash (undoable).
- Open a larger AI chat with the current note as context, and get faster, more accurate workspace search.
- More reliable Google Drive sync and backups, plus a Drive maintenance tool in storage settings.
- Note and meeting covers with art from The Met, a full-width note header, and cover thumbnails in All Notes.
- An update button in the desktop header when a new version is ready.
- Removed leftover cloud services and crash reporting. Link previews now load directly on your device.
- Smoother trackpad pinch zoom and safer web page reading in the AI assistant.
