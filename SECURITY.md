# Security reports

Report vulnerabilities privately through [GitHub security advisories](https://github.com/madcodeorg/nota/security/advisories/new). Include the affected version, reproduction steps and the impact. Do not post credentials, private notes or recordings in public issues.

Public beta releases are under active development. Use the latest published build when reproducing a report. There is no promised response time or long-term support window yet.

For ordinary installation problems or bugs, use [GitHub issues](https://github.com/madcodeorg/nota/issues).
